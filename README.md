Name of the code: Cafe Inventory System

Description:
The Cafe Inventory System is a simple Python program (cafe.py) that demonstrates the use of lists, dictionaries, and basic arithmetic operations. The program stores menu items, their stock quantities, and prices, then calculates the total value of all stock held in the cafe

The program uses a menu list containing the cafe items, a stock dictionary containing the quantity available for each item,
a price dictionary containing the price of each items. 
There is a variable called total_stock to calculate the total value of all inventory.
